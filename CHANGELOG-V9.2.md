# V9.2 — Import de contacts Samsar

- Samsar → **Importer des contacts** : fichier vCard (.vcf), CSV, ou liste collée.
- Numéros marocains (06…, 07…, 05…) convertis au format international pour WhatsApp ; numéros étrangers conservés.
- Détection des doublons (déjà dans le carnet, ou répétés dans le fichier) et des numéros invalides.
- Contrôle avant import : cocher/décocher, corriger les noms, zone/spécialité/source communes.
- Un 2e numéro d'un même contact est gardé dans les notes. Maximum 300 contacts par import.
- Google Apps Script inchangé (aucun redéploiement).
